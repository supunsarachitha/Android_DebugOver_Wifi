# 📡 Android Debug Over WiFi

A simple desktop utility that enables Android developers to connect their devices to ADB over WiFi — no more fumbling with USB cables once you're set up!

---

## 🧰 Features

- 🔌 Enable ADB over WiFi with one click
- 📱 Connect Android devices wirelessly for debugging
- 🖥️ Built with C# and .NET for Windows environments
- 🧼 Minimal UI, easy to use

---

## 🚀 Getting Started

### Requirements

- Android device with Developer Options enabled
- USB cable (for initial setup only)
- ADB installed on your system
- .NET Framework (for running the app)

### Usage

1. Connect your Android device via USB
2. Enable **USB Debugging** on the device
3. Launch the app
4. Click **Enable WiFi Debugging**
5. Disconnect USB and connect via IP shown on your device
